# Planner game data 1.2

`game-data-1.2.json` is the vendored Satisfactory 1.2 dataset used by the planner. It is
generated by `scripts/build-game-data.mjs`; do not edit it by hand.

## Schema (schemaVersion 1)

- `items`: `Desc_*_C` → `{ id, name, form, sinkPoints }`; `form` is `solid`, `liquid`, `gas` or
  `unknown`. Only items referenced by recipes, extractor resources or generator fuels are kept.
- `recipes`: `Recipe_*_C` → `{ id, name, duration, inputs, outputs, producedIn, variablePower? }`.
  Inputs/outputs are `{ item, amount }` at 100% clock; rates are computed at load time. Liquid and
  gas amounts are converted from the game's litres to m³, so recipe rates and extractor rates use
  the same unit. Recipes with no item inputs (for example `Recipe_QuantumEnergy_C`) are kept as
  power-only production recipes.
  Only recipes produced in a known manufacturing machine are kept.
- `machines`: `Build_*_C` → `{ id, name, basePower, powerExponent, boostPowerExponent, shardSlots }`.
- `extractors`: `{ id, name, baseRate, form, basePower, powerExponent, allowedResources }`.
  Fluid `baseRate` is already in m³/min.
- `generators`: `{ id, name, powerProduction, fuels[] }`.
- `belts`: `{ id, name, rate }` in items/min (converted from the game's `mSpeed / 2`).
- `pipes`: `{ id, name, rate }` in m³/min (`mFlowLimit * 60`).
- `saveVersionMax`: highest save header version the dataset is known to cover (58 for 1.2).

## Updating

1. Pick a new pinned `Docs/en-US.json` source. Prefer a repository that states the game version and
   has a permissive licence; record the commit and file hash.
2. If the source moved, update `SOURCE_URL`, `SOURCE_COMMIT`, `SOURCE_SHA256`, `GAME_VERSION` and
   `SAVE_VERSION_MAX` at the top of `scripts/build-game-data.mjs`.
3. Run the script. Network access is required unless a local copy is supplied:

   ```bash
   export PATH="$HOME/.local/bin:$PATH"
   node scripts/build-game-data.mjs
   # or
   node scripts/build-game-data.mjs --input /path/to/Docs/en-US.json
   ```

   The script rejects a downloaded file whose SHA-256 does not match the pinned hash. With
   `--input`, update the recorded hash deliberately after reviewing the file.
4. Review the generated diff, especially items/recipes/machines/extractors/generators, and update
   `src/features/satisfactory_planner/domain/save-mapping.md` if property names or class names changed.
5. Run `npm run typecheck`, `npm test`, `npm run test:coverage`, and `npm run build`.

The committed dataset is about 200 KB; the raw Docs file is about 10 MB and must not be committed.
